
# Hotel Management System (Frontend)

A modern web application built with Next.js for managing hotel operations, bookings, and guest services.

---

## 🚀 Quick Start Guide

Follow these steps to set up and run the project locally.

### 1. Clone the Repository
```bash
git clone https://github.com/Rashedul2001/Hotel-Management-System-Frontend-NextJS.git
cd Hotel-Management-System-Frontend-NextJS

```

### 2. Install Dependencies

Open a terminal inside the project root folder and run:

```bash
npm install

```

### 3. Environment Configuration

Create a `.env.local` file in the root directory and define your required environment variables:

```env
# Example environment variables
NEXT_PUBLIC_API_BASE_URL=http://localhost:5000/api

```

### 4. Run the Application

Start the development server:

```bash
npm run dev

```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## 🤝 Contributing Guidelines

We welcome contributions! Please follow these steps to contribute to the project:

1. **Fork the Repository**
Click the **Fork** button at the top right of this repository page to create your own copy.
2. **Clone Your Fork**
```bash
git clone [https://github.com/YOUR-USERNAME/Hotel-Management-System-Frontend-NextJS.git](https://github.com/YOUR-USERNAME/Hotel-Management-System-Frontend-NextJS.git)
cd Hotel-Management-System-Frontend-NextJS

```


3. **Configure Upstream Remote**
Keep your fork synced with the main repository:
```bash
git remote add upstream [https://github.com/Rashedul2001/Hotel-Management-System-Frontend-NextJS.git](https://github.com/Rashedul2001/Hotel-Management-System-Frontend-NextJS.git)

```


4. **Create a Feature Branch**
```bash
git checkout -b feature/your-feature-name

```


5. **Make Changes and Push**
Commit your changes with descriptive messages and push them to your fork:
```bash
git add .
git commit -m "feat: add user booking history UI"
git push origin feature/your-feature-name

```


6. **Create a Pull Request**
Go to the original repository on GitHub and click **Compare & pull request** to submit your changes for review.
